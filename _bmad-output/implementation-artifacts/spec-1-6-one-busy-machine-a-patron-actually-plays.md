## Intent

**Problem:** B0 performs itself in attract and the seat is always free — no one stands at the machine, the screen never shows a run in progress, and the epic's payoff "watching a Patron actually play Moon Patrol" is missing. The sim also has no `autoplay(seed)` hook (1.1 opened the wrapper method; the sim never implemented it), so "busy" cannot be real, and the vendored respawn-pad bug (DW-25) sits squarely in the path autoplay drives to a real end state.

**Approach:** Land the autoplay path end to end. Sim: `autoplay(seed)` + a deterministic autoplay AI (`games/moon-patrol/sim/autoplay.js`) synthesizing `step()`'s boolean input inside `tick()`, runs ending at canonical `gameEnded`/`roundBreak` within a measured tick bound (AD-8 L1 "busy is a texture, not a lock"). Kernel: `core/patrons/` — a scheduler (occupancy + queue + break arbitration with derived seeds), an impulse stage (authored per-game event→impulse mapping, carried through the generated registry, → kernel reaction-library data), and a presenter (Patron figure state machine animated in-tick; render only re-poses meshes, the coin-door-pose idiom). Event dispatch becomes the "patrons" system's single per-tick drain (AD-23 fixed order: sim ticks → event dispatch → scheduler decisions → input routing), forwarding records to the seat and presentation sinks; the seat grows arbitration-aware (wait at a busy cabinet instead of sitting). DW-25: fix the respawn pad-clear predicate upstream at `C:/git/moonpatrol` (working tree), re-vendor `world.js`, and pin a sim test.

## Boundaries & Constraints

**Always:** the busy designation is provisional authored room data — `CabinetPlacement.busy?: boolean` (B0 true), the carrier the Epic 3 Manifest `busy` field (AD-12) will replace; the scheduler reads placements, never hand-typed ids. A busy Cabinet runs the real autoplay hook: `instance.autoplay(derivedSeed)` — no separate busy animation exists anywhere (AD-23). Derived seeds come from the registry entry's authored seed plus a per-run counter through fixed 32-bit kernel arithmetic (AD-4 derived role; tick-derived scheduler state; visitor play keeps the kernel-fresh seedFn). The autoplay AI lives in the sim half, reads only world state, emits exactly `{left,right,jump,fire}`, imports only its own sim (depcheck sim leg + lint-bans auto-scan bind it), is deterministic, and every seeded autoplay run emits `gameEnded` or `roundBreak` within a measured bound (measure the bound at implement, pin with headroom). In-tick order stands: loop instance ticks, then kernel systems in registration order — "patrons" (drain, impulse stage, arbitration) before "seat" (input mapping for the next tick); `core/loop.ts` is NOT edited — one consumer per tick (patrons dispatch), seat and presentation sinks receive the forwarded records. Reactions: sim event → authored mapping data asset (`games/moon-patrol/assets/impulse-mapping.json`) → kernel reaction library (flinch/slam/jump, authored data in `core/patrons/`) → kernel presenter animates the figure; one reaction per mapped event (finite authored duration, re-trigger replaces), unmapped events produce nothing, reactions never loop on their own (AD-6, AD-23). The figure is animated by the kernel presenter — `games/moon-patrol/presentation/` stays byte-unchanged (diff pin); figure state is kernel tick state (AD-3), placed at `playPoseFor(volumeId)`. Arbitration at a busy Cabinet: E opens the coin door (1.4 law), second E = wait (join queue, pose untouched, Patron keeps playing), third E un-waits; at each canonical break a physically-present waiting Visitor (within `TARGET_REACH` of the placement, (inference)) beats the queue head and takes over through the seat (play pose teleport, kernel-fresh seed, figure lifts off); with nobody, autoplay restarts at that same break with a new derived seed (busy never withholds); a Visitor who walked away fails presence, the run simply continues. A seated Visitor's `gameEnded` returns the machine to attract in place with the Visitor still seated (1.5 law survives, now owned by the scheduler for busy cabinets; the seat keeps the flip for tracked-not-busy cabinets) and Enter restarts seat-local; the Patron never reclaims a seated chair; when the Visitor stands, the scheduler re-arms autoplay after the authored attract dwell (same dwell gates the first autoplay after boot).
