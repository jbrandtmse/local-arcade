The rules etched on this plan

  • Pull signals, in order: 1) sound effects → 2) bright attract-mode graphics/animation → 3) player intensity (jerking on controls, talking, bantering).
  • NO DEAD MACHINES. Every cabinet always performs — attract mode running, marquee lit, screen moving. If a screenshot looks static, it failed.
  • One animated system: game events → agent impulse → body reaction (flinch, slam, jump); player inputs → game state. Body language is a broadcast channel — drama readable from across the room.
  • Find, never announce: the arcade never breaks character; model names are metadata you go looking for (instruction card behind the coin door; archives/click-through outside the fiction).
  • No guided play, no forced order. The crowd of machines IS the content; patrons set the stage, real visitors fill it.
  • The timeline scales: every themed corner is a museum of its own tech — main rows 1978→1985, pinball corner EM→DMD→modern→custom.
