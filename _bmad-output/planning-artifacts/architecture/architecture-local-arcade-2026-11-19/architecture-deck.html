microkernel · deterministic runtime · sealed build — AD-18

Three laws everything in the spine serves

Every invariant exists to keep one of these provable.
1

Patrons really play

A busy Cabinet is a Patron playing via the game’s own autoplay(seed) — no fake busy animation, busy is never permanent, takeover happens at gameEnded / roundBreak.

2

CI verifies in seconds, no browser

L1 is headless: same seed → same stateHash, and a seeded autoplay must run to a real end state. Registration refuses a red gate.

3

Sound finds games

Occluded spatial audio is the first pull signal — you hear a game around a pillar before you see it. The room never points at anything (no HUD, no waypoints).
